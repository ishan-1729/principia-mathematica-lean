# Whitehead and Russell, *Principia Mathematica*, in Lean 4

*Principia Mathematica*, Volumes I and II (second edition), formalized proposition by proposition in Lean 4 and mathlib, from the Project Gutenberg texts ([#78050](https://www.gutenberg.org/ebooks/78050), [#78255](https://www.gutenberg.org/ebooks/78255); public domain in the USA). Volume III will be added once its Gutenberg edition is published.

> **Work in progress.** Every numbered proposition of Volumes I and II has a Lean declaration and a status. A pass proving the propositions still marked `stated (open here)` is under way, and the documentation is not yet written.

## Status

Every proposition `✱N·M` is the declaration `pmN_M`. Its docstring gives the formula as printed. The full map, with each number's file, is [docs/PROPOSITIONS.md](docs/PROPOSITIONS.md), generated by `scripts/prop_table.py`.

| Status | Propositions |
|---|---|
| proved | 6004 |
| proved (reading): the printed formula admits more than one reading in Lean; the docstring explains the one taken | 804 |
| definition | 332 |
| proved (corrected): false as printed; a counterexample and the corrected statement are proved | 64 |
| remark | 17 |
| stated (open here): stated, not yet proved | 83 |
| **total** | **7304**, with no `sorry` |

## Layout

```
PrincipiaMathematica.lean            root: imports everything
PrincipiaMathematica/Basic.lean      conventions: dots, types, descriptions, classes, relations, symbol table
PrincipiaMathematica/Defs/PartN.lean the definitions (Df) of Part N
PrincipiaMathematica/Introduction.lean
PrincipiaMathematica/PartN/SectionX.lean
data/principia.json                  the text, extracted from the Gutenberg HTML
docs/PROPOSITIONS.md                 generated proposition map
scripts/                             extraction, skeletons, proposition map, axiom audit, checker
```

## Building

Lean v4.36.0 and mathlib v4.36.0 are pinned in `lean-toolchain` and `lakefile.toml`.

```sh
lake exe cache get                       # download prebuilt mathlib
lake build
lake env lean scripts/AxiomsAudit.lean   # only propext, Classical.choice, Quot.sound
python3 scripts/prop_table.py --check
```

The files are large. On a machine with less than about 32 GB of RAM, build a few modules at a time, or check one file with `python3 scripts/check.py PrincipiaMathematica/Part1/SectionA.lean`.
